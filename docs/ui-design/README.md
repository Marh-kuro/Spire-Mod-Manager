# UI 设计资源

本目录用于存放 spinemanager 的 UI 设计稿（截图 / 导出图），开发时参考实现，保证界面与设计一致。

## 目录结构

设计稿可按页面分子目录存放，也可直接平铺在本目录：

```
docs/ui-design/
├── README.md            # 本说明
├── main-window/         # 主窗口设计稿
├── settings/            # 设置界面设计稿
└── components/          # 通用组件（按钮、开关、列表项等）
```

## 文件命名规范

格式：`页面名-状态.扩展名`

- 主窗口默认状态：`main-window-default.png`
- 设置界面：`settings-paths.png`
- 同一页多个版本用序号：`main-window-v2.png`

## 图片格式与要求

| 项目 | 要求 |
| --- | --- |
| 格式 | 优先 **PDF（矢量）** 或 **SVG**；其次 PNG（1x，不缩放） |
| 文字 | 文字图层**不要栅格化/转曲线**，保留文本层，便于提取按钮/标题文字 |
| 尺寸 | 按实际界面尺寸（如 1920×1080 或指定窗口尺寸）导出，1x 即可 |
| 颜色 | 建议附配色表（主色 / 背景 / 文字 / 边框 / 强调色的 hex 值） |
| 导出 | 每个部件**单独导出**，不要整页合并成一张图 |

## 配套说明（推荐）

每张图配一行文字描述，例如：

> `topbar.pdf`：顶部工具栏，浅灰底，左侧标题「Spine Mod Manager」，右侧 3 个按钮（启动 / 扫描 / 设置）

这样可结合「矢量结构提取 + 文字说明」精确复刻界面。

## 开发对照

实现对应界面时，以本目录设计稿为准，重点关注：

1. 整体布局（工具栏 / 列表 / 详情分区）
2. 配色（主色、背景色、文字色）
3. 控件样式（列表项、按钮、开关、复选框）
4. 交互（拖拽排序、多选批量操作、启动/扫描按钮位置）
